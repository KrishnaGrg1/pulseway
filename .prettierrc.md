# Prettier Configuration

This project uses Prettier for code formatting with the following setup:

## Configuration

- **Semi**: No semicolons
- **Single Quote**: Yes
- **Tab Width**: 2 spaces
- **Print Width**: 100 characters
- **Trailing Comma**: ES5
- **Arrow Parens**: Always
- **Plugins**: Tailwind CSS class sorting

## Usage

### Format all files
```bash
bun run format
```

### Check formatting (without modifying)
```bash
bun run format:check
```

### VS Code Integration

If you're using VS Code, the project includes settings to:
- Format on save automatically
- Use Prettier as the default formatter

Make sure you have the **Prettier - Code formatter** extension installed:
```
ext install esbenp.prettier-vscode
```

## Ignored Files

Check `.prettierignore` for files that are excluded from formatting (build outputs, generated files, etc.)
